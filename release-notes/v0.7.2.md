## New and Noteworthy

- **MCP tool annotations.** Every tool now advertises a display title and the MCP behavior hints (`readOnlyHint`, `destructiveHint`, `idempotentHint`, `openWorldHint`), so a client can tell reads from writes without guessing: eight tools are marked read-only, `write_engram` is marked non-destructive because capturing knowledge is additive by default and only the five GitHub-facing tools are marked open-world. Hosts that honor the hints prompt less on the capture loop and can batch the read-only calls; the hints are advisory and Crystalline's own read-only and collaboration gating stays authoritative.
- **The bundle got a face.** The MCP Bundle now ships the Crystalline logo as its icon, so the extension is recognizable in Claude Desktop's extension list instead of a placeholder.

## Fixes

- **Claude Desktop chat mode connects reliably.** Two startup hardenings for machines that still saw failed sessions: the version-negotiation probe (`server/discover`) is now answered immediately, concurrently with daemon startup, instead of waiting out a cold daemon spawn; and when the server genuinely cannot start (index lock held by another instance, config or store errors) it now answers `initialize` with a readable JSON-RPC error instead of closing the pipe, which Claude Desktop's SDK treats as an unrecoverable network error and never retries. A failed daemon handshake also falls back to the in-process server instead of exiting.
- **GitHub tokens land in the OS keychain again.** keyring 4.1.4 fixes the upstream bug that made every keychain probe report "no default store", so the platform-native credential store (Apple Keychain, Windows Credential Manager, Secret Service) is used as designed and Crystalline's workaround was removed. The 0600 file fallback for headless machines is unchanged.
- **"Developed by Jordi Böhme."** The bundle manifest and the Debian package now carry the right author name, sourced from the workspace manifest.

## Breaking changes

- None. The tool surface, tool names and schemas are unchanged; annotations are additive metadata.
