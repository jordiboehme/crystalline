## New and Noteworthy

- **One keychain prompt, not one per domain.** On macOS the GitHub token is now read from the credential store exactly once per process and cached for its lifetime, refreshed by a connect and dropped when GitHub says the token no longer authenticates. Previously every origin operation re-read the keychain twice per connected domain and the background poller re-read on every tick, so users who had not granted "Always Allow" saw the Keychain dialog storm reported this week. Connecting now costs a single keychain write with no reads, and `crystalline doctor` a single read. Being asked once again after an extension update is expected while the binaries are unsigned.
- **Version takeover, hardened.** A newer Crystalline still shuts down an outdated running daemon on first contact and takes over - now it also re-drives its own daemon spawn when another client's old bridge respawns the outdated version into the takeover window, so upgrades converge instead of occasionally timing out into a dead session.

## Fixes

- **Claude Desktop chat mode no longer hangs on a failed start.** The version-negotiation probe is answered immediately and concurrently with daemon startup, a failed daemon handshake falls back to the in-process server, and a startup that genuinely cannot proceed answers `initialize` with a readable JSON-RPC error instead of closing the pipe - which chat mode's client used to sit out as a 60s timeout, exactly the field log captured during a 0.7.1 to 0.7.2 update.
- **Clean extension identity.** The bundle manifest now carries the ASCII author form, so Claude Desktop's extension ID becomes `local.mcpb.jordi-boehme.crystalline` instead of mangling the umlaut. Note: this changes the extension identity one final time - Desktop will treat this update as a new extension (re-enable it after installing), and the one-time Keychain prompt follows from the new binary path.

## Breaking changes

- None in the protocol or tool surface. The extension ID change above is a one-time Desktop-side identity reset for mcpb installs.
