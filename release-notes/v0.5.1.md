## New & Noteworthy

- **Read before you cite.** A production session caught an agent answering "what is this project about?" from a search snippet: confidently, plausibly and thinly. The routing and memory skills now teach the discipline - a snippet is a ~200-character targeting aid, never a source. Overview questions require reading every strong hit, what you read earlier for another task does not count as coverage and an honest answer names what it left unread.
- The `search_engrams` tool description now says out loud that hits carry partial snippets and that `read_engram` holds the whole engram, so even a harness without the skills installed gets the memo.

## Fixes

- Removed the routing-skill sentence that blessed answering from snippets. It was technically permission and practically a trap.
- The skills now note that `build_context` returns titles and relations, not content - reads follow it.

## Breaking changes

None.
