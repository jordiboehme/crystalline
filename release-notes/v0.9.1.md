## New & Noteworthy

- **Token-efficient tool results.** List-shaped MCP tool results (search hits, recent activity, domain listings, browse, context and status reports) now arrive TOON encoded, cutting their token cost by 14-35% on measured real payloads while document reads and confirmations stay JSON. The server's initialize instructions describe the format to the connected agent. Set `service.response_format=json` (or `CRYSTALLINE_SERVICE_RESPONSE_FORMAT=json`) to restore plain JSON - switchable at runtime through `configure`.
- **macOS privacy denials explain themselves.** When macOS privacy protection blocks access to a protected folder such as `~/Documents`, the error now says so and points at the fix (System Settings > Privacy & Security > Files and Folders for the app that runs Crystalline, or Full Disk Access) instead of a bare "Operation not permitted".
- **Playbook rework.** The playbook is restructured around use cases with an agent-first flow and needs a terminal exactly once.

## Fixes

- A domain root the daemon cannot read now fails its sync loudly instead of scanning as empty and clearing that domain's search index. The startup sweep contains the failure per domain and keeps syncing the others; the index rebuilds on the first sync after access is restored
- CLI data commands against a running daemon now fetch engine JSON over the control socket instead of parsing the MCP wire text, so `--json` output stays byte-stable regardless of the response format setting

## Breaking changes

- The MCP wire format for list-shaped tool results defaults to TOON after upgrade. An integration that parses those tool results as JSON text sees TOON instead; set `service.response_format=json` to keep the previous format
