## New & Noteworthy

- **The memory skill went back to school.** `crystalline-memory` was retrained against the benchmark harness and the lessons that generalize were ported into the shipped skill by hand: search before every write, commit to the obvious domain on the first call, date-window filters through the metadata object and the full supersede recipe. Held-out benchmark score climbed from 0.63 to 0.71 averaged over two runs (0.74 at best). If `crystalline install` set up your skills, your next session start picks up the new copy automatically.
- **One-step server installs.** The `.deb` now ships a systemd unit, installed disabled so nothing starts behind your back: drop overrides into `/etc/default/crystalline` (bind address, read-only mode, team domains) and `sudo systemctl enable --now crystalline`. The daemon runs under a dynamic service user with its state in `/var/lib/crystalline` and config in `/etc/crystalline`; upgrades restart the service only if it was running. docs/deployment.md walks through the new [Linux server with systemd](https://github.com/jordiboehme/crystalline/blob/main/docs/deployment.md#linux-server-with-systemd) scenario.
- **A health endpoint monitors can love.** Every HTTP endpoint answers `GET /health` with a static `{"status":"ok","version":...}` body - point Gatus, a load balancer or a Kubernetes probe at it, no MCP handshake required and no queueing behind indexing.
- **The container checks its own pulse.** The image ships a built-in `HEALTHCHECK` backed by the new `crystalline healthcheck` probe (a plain loopback GET with one hard deadline), so `docker ps` shows health and compose services can gate on `service_healthy`. Works in the distroless image precisely because it needs no shell and no curl.
- **Five benchmarks keep the skills honest.** The eval harness gained retrieval-depth items that punish answering from search snippets instead of reading the knowledge, plus a complete collaboration benchmark (team domains, proposals, conflict resolution, onboarding) that runs every scenario against an in-process fake GitHub. Calibrated and ready to train the collaboration skill next.
