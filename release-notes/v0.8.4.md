# Don't wait up

## New & Noteworthy

- Connecting a team knowledge repository now streams live progress (downloading, registering, indexing, connected) to MCP clients that request it, so even slow connects keep the session alive
- Embedding now runs on a background worker everywhere: connect, update and sync return as soon as knowledge is text-searchable and semantic search fills in as the worker catches up

## Fixes

- Connecting a large knowledge repository through Claude Desktop no longer times out: the connect returns in seconds instead of embedding every engram inside the request
- Retrying a connect that already succeeded reports the connected state with `already_connected: true` instead of failing with "domain is already connected"
- A retry racing a still-running first connect waits and answers idempotently instead of downloading the repository a second time
- The daemon's file watcher no longer stalls on embedding passes and bursts of changes coalesce into single background passes

## Breaking changes

None.
