# I'll be back.

Fluid works in Safari again where it asks twice, your name is yours to change, and the editor knows Tab in lists.

## New & Noteworthy

**Change your own display name.** Profile has a field for your display name now. Before, only an admin could change it. A sign-in through SSO or a proxy sets the name once, when the account is created. A later sign-in does not overwrite a name you chose. The name is trimmed and has at most 100 characters. Control characters and invisible characters are refused. An empty name goes back to the login name. The same rules apply when an admin sets a name.

**Tab and Shift+Tab in lists.** In a list item, Tab nests the item under the item above it, and Shift+Tab lifts it out again. Sub-items move with it. One undo takes it back. This works for bullets, numbered lists and task lists, in engrams and in the Reflection. On any other line Tab still moves the focus, as before. To leave the editor from a list, press Escape and then Tab.

**Text styles in the quick format bar.** The bar above a selection now has the same text style menu as the toolbar, so you can make a line a heading without going up to the toolbar.

**A clearer GitHub connection page.** The page first says how the instance reaches GitHub: through the App, with a token or not at all. With an App, the other ways to connect are folded away, because the instance does not use a token while the App works. Disconnect only shows when there is a token to remove, and it says what it removes. The App card speaks in sentences instead of lines like "Client secret: set".

**Administration in the menu.** The admin entries in the avatar menu sit under "Administration" now: "Users" and "GitHub connection". The old entry "Settings" looked like the settings of the signed-in person.

## Fixes

- In Safari, a button that asks twice did nothing on the second press. Deleting a user, revoking a token and disconnecting were affected. Safari does not focus a button when it is clicked. It moves the focus to the page instead, and that closed the question before the click arrived. The browser tests now run these steps in Safari's engine too.
- In the Users table, Delete, Confirm delete and Keep wrapped badly and "Confirm delete" broke over two lines.
- When you edit together with somebody, Safari left copies of their name flag behind when their cursor moved.
- The container images are pushed only after the release is published. Before, a release that failed at signing had already pushed its images.

## Breaking changes

None. One change in behaviour: an SSO or proxy sign-in no longer refreshes the display name on every sign-in. It sets it only when the account is created. The email address is still refreshed.
