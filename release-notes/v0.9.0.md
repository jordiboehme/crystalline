## New & Noteworthy

- **The knowledge graph got real edges.** Prose wikilinks (`[[Title]]`, including the cross-domain `[[domain:Title]]` form) now resolve into the index like typed relations do, so `build_context` follows them and inbound references are exact instead of text-matched. Pre-existing virtual domains resolve their prose links on their next write or a `crystalline reindex --full`.
- **Reads tell you there is more.** `read_engram` now marks every relation and link as resolved or not, adds an inbound summary (who points here, up to 5 referrers) and names a ready `build_context` anchor whenever linked knowledge exists.
- **A vocabulary you can see.** The new `vocabulary` tool (and `crystalline vocabulary`) lists tags with usage counts, observation categories and relation types for one domain or all of them, and reports near-duplicate tag clusters so drift is visible before it spreads. Search hits now carry their engram's tags too. The MCP surface is now 15 tools, 19 with team domains enabled.
- **Tag hygiene, end to end.** Tag identity is case-folded (`API` and `api` are one tag), `crystalline tags rename` and `tags merge` rewrite files surgically with a dry-run preview and confirmation, and `crystalline doctor` surfaces cluster advisories.
- **Tag aliases make merges reversible.** A domain MANIFEST can carry a `## Tag Aliases` section (`- old-name -> canonical-name`); searches fold old tag names into their canonical class in both directions and `tags merge` records the alias automatically (`--no-alias` opts out). Undo is deleting one line.
- **Schema drift on demand.** `validate_engrams` accepts `drift: true` and reports observation categories and relation types in use but undeclared, and declared but unused, per schema entity.
- **The Crystalline Playbook.** docs/playbook.md is a mission-based training course for new users - eight missions from first domain to team sharing, agent-first with CLI equivalents and a cheatsheet, aboard the SS Kobayashi Delorean.
- **Skills teach all of it.** The four topical skills and the Claude Desktop skill now cover the vocabulary tool, hit tags, the read enrichment signals, drift and propose-first alias upkeep.
- **Leaner tool schemas for picky clients.** Advertised MCP tool schemas are sanitized to a conservative shape for maximum client compatibility, including Claude Desktop.

## Fixes

- Inbound reference kinds decode correctly on the postgres backend (relation vs link was collapsed before).
- A merge whose old tag is already aliased to a different canonical no longer records an inert alias and claims success; the conflict is reported and the MANIFEST left untouched.
- Tag rewrites respect nested code fences and separator-variant merges are no longer rejected.

## Breaking changes

- Index schema migrates to turso v8 / postgres v7 automatically on first open; a wipe plus `crystalline reindex --full` remains a valid upgrade path. Tag rows are case-folded by a data migration; files keep their verbatim tag text.
- Tag searches and filters are now case-insensitive and alias-aware, which can return more results than before for the same query.
- Existing domains gain alias folding per domain on their next sync.
