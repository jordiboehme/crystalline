## New & Noteworthy

- **Skills that went to school.** A skill-training harness (built on SkillOpt) benchmarks the shipped skills against real headless agent sessions with deterministic scoring - no LLM judge, no vibes. The routing, capture and schema skills each shipped measurably better after training runs: sharper domain targeting, edit-over-create discipline before anything is written and Picoschema authoring that passes verification on the first try.
- **Installs that keep themselves fresh.** Every install writes a receipt; hooks and skills refresh themselves at session start after an upgrade, and doctor reports receipt skew and retired leftovers instead of leaving you to diff directories by hand.

## Fixes

- `search_engrams` and `write_engram` now accept nested arguments arriving as JSON-encoded strings. Agents love stringifying nested objects; now they may. (Both bugs were found by the training harness, which is how a benchmark pays rent.)

## Breaking changes

- The skill release zips are renamed for their audiences; adjust download scripts accordingly.
