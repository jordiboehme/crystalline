# Lost in translation

The end-of-session check works again in older Claude Code versions.

## Fixes

**Older Claude Code rejected the Stop hook with "Invalid input".** When a
session ended, older Claude Code versions (2.1.104, for example) showed this
and skipped the check for learnings:

> Stop hook error: JSON validation failed: Hook JSON output validation failed:
> - : Invalid input

The Stop hook's answer carried an extra block for Claude Code
(`hookSpecificOutput` with `hookEventName: "Stop"`). Older versions don't know
that block for Stop, so they threw away the whole answer. The newest version
(2.1.281) accepts the block but ignores what was in it. So the block is gone now. The
check still arrives the documented way (`decision` and `reason`), and it works
in old and new versions alike.

Upgrade Crystalline and the error is gone. No change to your hooks is needed.

Claude Code still shows "Stop hook error occurred" when the check asks the
agent to keep going. That line comes from Claude Code on every blocked stop,
not from Crystalline.

## Breaking changes

None.
