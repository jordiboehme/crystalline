## New & Noteworthy

- **Read-only serving.** Pass `--read-only` and the write tools vanish from the tool list: agents consume curated knowledge without redecorating it. The routing prompt adjusts itself to match.
- **Deployment scenarios, drawn.** docs/deployment.md walks each deployment shape with a diagram, so you can point at the one you are running.
- **A heavier image that saves you a download.** A container variant ships with the embedding model baked in, for hosts that should never touch the network.
- **Prompts, reorganized.** Prompt generation now comes in kinds, and the system prompt is bound to the MCP tools it actually talks about.

## Fixes

- A domain added mid-session is indexed immediately instead of waiting for the watcher to notice it exists.
- Closed a race where a freshly added domain could escape the file watcher entirely.

## Breaking changes

None.
