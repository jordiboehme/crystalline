# Call Me Ishmael

Fluid now calls people by the name they chose, and a new line in the editor is a new line on the page.

## New & Noteworthy

**Your display name, everywhere.** You set your display name in your profile, but most of Fluid still showed your login name. A comment in a thread said `jordi.example.com` instead of "Jordi". Now Fluid shows the display name wherever it names a person: thread comments, "waiting for", print notes, "changed by", "Shared on purpose by", kept texts, the engram details, "Updated by", drafts and draft links. Lists where you must tell people apart show both, for example "Jordi (jordi.example.com)": members, Reflection collaborators, invites and the admin notices. Point at a name and a tooltip shows the login name. The files still record the login name, because it never changes. So when someone changes their display name, every page shows the new name at once. Agents keep their own names.

## Fixes

- In the editor, Enter in a paragraph wrote a single line break. The page showed the lines on their own while you wrote, but the viewer joined them into one block, as Markdown does. Now Enter starts a new paragraph, and Shift+Enter writes a line break inside the paragraph. Lists, quotes, tables and code keep their own Enter. Pages you wrote before keep their text: edit them once to split the lines.

## Breaking changes

None. Enter in a paragraph now writes an empty line, so your Markdown files get blank lines where they had single line breaks before.
