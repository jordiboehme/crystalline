## New & Noteworthy

- **One-click Claude Desktop install.** The release now ships an MCPB bundle: a native folder picker, no terminal, no YAML. Every picked folder becomes a domain automatically, MANIFEST included.
- **`crystalline mcp --domain <folder>`** registers knowledge folders on the way up, scaffolding what is missing.
- **An ASCII logo.** In the README and the serve banner. Zero functional value. No regrets.
