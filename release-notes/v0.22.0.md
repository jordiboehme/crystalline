# Crisis on Infinite Earths

Crystalline can now point at two engrams that say opposite things. Wrapped bullets are read whole and every file is written with plain line endings.

## New & Noteworthy

**Possible contradictions.** Knowledge drifts. One engram says the proxy runs in the access account. Another one, written months later, says it moved. Nobody remembers to retire the old one. With `evolve.contradictions` set to `full`, the daemon reads the observation lines of related engrams with a local language model (German, English and mixed). `crystalline evolve` then shows a new finding, V302, for two lines that look like they contradict each other. It is a question, never a verdict: read both engrams, then supersede the wrong one, close the older one's validity window or acknowledge the pair.

- Off by default. Nothing is downloaded or scored until you run `crystalline config set evolve.contradictions full`. The model is a download of about 550 MB. While it is loaded it needs a lot of memory: about 2.6 GB on the CPU, and on Apple Silicon about 1.8 GB (up to 3.2 GB while it scores). It is unloaded again 10 to 15 minutes after the daemon has nothing left to score.
- Only lines about the same subject reach the model, and only for current engrams: drafts, ideas and engrams past their `valid_to` are left out.
- One finding per pair of engrams, with both lines, the model's probability and how similar the two lines are. At most ten per domain, the most likely first.
- On Apple Silicon the model runs on the GPU.
- `crystalline status` and `crystalline doctor` show the setting, the model and how much is still waiting to be scored. The web UI's Maintenance page shows both lines of a finding.
- A finding needs a probability of 0.95 or more. In our tests every real contradiction scored above that, and below it most findings were noise. The model can still be wrong, so tell us what you see.

**A bullet that wraps is one observation.** A long bullet that continues on the next lines used to be read as its first line only, so search, the vocabulary and the link graph saw half a sentence. Now the whole bullet is one observation (its line number is still the first line).

- After the upgrade the first sync reads every engram once more: from its file, or for a virtual domain from its stored text. No file and no stored text is changed. Nothing needs to be run by hand. Open review drafts are read again on their next save.
- A `#tag` at the end of the first line of a wrapped bullet is now part of the text. Only the tags at the end of the whole bullet count.
- Team on a shared Postgres database: an edit during that first sync can fail once. Just try it again.

**Tags can be set as a list.** `edit_engram` with `set_frontmatter` takes `values` for `tags`, so an agent can replace the tags of an engram in one call instead of rewriting the frontmatter by hand. Tags are folded to lowercase-with-hyphens on the way in.

**Plain line endings.** Crystalline accepts files and parameters with Windows line endings (CRLF) and always stores and returns LF. A CRLF file is still read and searched as it is. It becomes LF the next time Crystalline writes it. `crystalline verify` now reports a file that is not valid UTF-8 (E006) instead of stopping, and reading or editing such a file is refused with one line.

**A Reload button.** When the web UI in your browser is older than the daemon, the banner at the bottom now has a Reload button. Before, you had to know that reloading the page fixes it.

**Ingesting a big source.** The capture skill now suggests splitting a large source by topic and letting capable subagents fold in one topic each.

**Updates.** Rust 1.99.0 and the usual updates. Nothing changes in how you use Crystalline.

## Fixes

**Metal could fail and take search with it.** If the GPU failed after the embedding model had loaded fine, search kept failing until you restarted with `CRYSTALLINE_ACCELERATION=off`. Now the model moves to the CPU on its own and `crystalline status` says why.

**Half sentences in search and in evolve.** Only the first line of a wrapped bullet was an observation (see above).

**A link at the start of a bullet became a category.** `- [Docs](https://...) - text` was read as an observation with the category "Docs". It is plain text now.

**The daemon could overwrite a broken config.** If `config.yaml` did not parse while the daemon adopted domain names after a sync, the daemon could save over it. Now it leaves the file alone and logs a warning until you fix it.

## Breaking changes

None.

- The index moves to schema v18 (v17 on Postgres). 0.21.3 refuses to open it and says the index is newer. To go back: export your virtual domains with `crystalline domain export` first (their engrams live only in the database), stop the daemon, move the index database aside and start the old version. It builds a new index from your files.
- Behaviour changes you may notice: observation counts and texts change for wrapped bullets, and a file with CRLF line endings is written with LF the next time Crystalline changes it.
