# Punch it

A fix release, and one you'll feel: on a big index, searching and saving are fast again.

## New & Noteworthy

- **The domain page got a Backup box and a Danger Zone.** Download archive and Import archive sit in Backup. Unregister domain, Make private and Share with everyone sit in the Danger Zone, and each of them asks you to type the domain's name before it does anything (the GitHub way). Both boxes live at the bottom of the page, after the team cards, and the Danger Zone is no longer part of Members.
- **Team sync says when it last checked, in your time.** "Last checked: 2026-09-17 14:32, 13 minutes ago" instead of a bare date. The clock is your browser's, the "ago" part ticks every minute, and "(stale)" still follows a check that failed.
- **The order menu sits where the list is.** It moved from the heading down to the row right above the engrams, beside the count. The caption under the heading is gone: the menu already says which way the list runs.

## Fixes

- **Searching and saving on a large index took minutes.** On an index with about ten thousand engrams and a couple of very long documents, every hybrid search and every `edit_engram` from an agent took two minutes or more, and `crystalline status` hung while they ran. Cause: a semantic search looks up the engram behind every chunk, and that lookup read the engram's whole body each time, so a 7 MB document with four thousand chunks cost 30 GB of copying per query. The body now lives in its own table and those lookups read a kilobyte. Same search results, same receipts, no re-embedding. Measured on a bench with thirty 2 MB documents: the query went from 1.6 s to 13 ms.
- **The similar-engrams advisory on a write receipt now says when it overran.** Its two-second budget could not cut a query that never yielded, so nothing in the log explained the wait. It warns now, with the elapsed time and the domain.

## Behaviour changes worth knowing

- **First start after the upgrade moves every engram body into the new table.** One transaction, done once. On a large index it takes a moment. Let it finish. The index file doesn't shrink afterwards (the old pages get reused by later writes), and the WAL briefly grows by about the size of the bodies.
- **Unregister and visibility need the domain name typed.** A second press was enough before.

## Breaking changes

None. The index schema moves to v15 on turso and v14 on Postgres, both migrate in place.
