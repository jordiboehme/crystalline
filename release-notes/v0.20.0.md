# Say my name

A domain now carries its own name, so links between domains survive every machine they travel to.

## New & Noteworthy

- The daemon's log lines now say which part of Crystalline they come from: `crystalline_engine`, `crystalline_rest`, `crystalline_identity` or `crystalline_service`. If your `RUST_LOG` filter names `crystalline_service`, it now only covers the daemon's own lines. Name the crate you want, or use a plain level like `debug`.
