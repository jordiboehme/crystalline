First public release. Crystalline gives AI agents durable memory: knowledge lives as plain markdown on your disk, agents learn while they work and nothing important evaporates when the session ends.

## New & Noteworthy

- **The format layer.** Engrams are markdown files with YAML frontmatter, organized into domains, each with a MANIFEST saying what belongs inside. `crystalline verify` runs a full static rule catalog with no database, no network and no excuses - there is a GitHub Action for it too.
- **Search that earns the name.** An embedded index with local embeddings: semantic, lexical and hybrid ranking. The index is disposable by design - your markdown is the truth, everything else can be rebuilt from it.
- **A daemon in the middle.** One background process owns the index, watches every domain and serves MCP over stdio to any number of agents. Single-instance locking means no two daemons ever fight over your knowledge.
- **Onboarding for agents.** A generated routing prompt tells an agent what knowledge exists and where to look before it asks its first question.
- **Getting knowledge in.** A generic importer for existing markdown knowledge bases, and `crystalline doctor` for when something feels off.
- **Shipping.** Release binaries named by platform, container images and agent skills to teach the workflow.
