## New & Noteworthy

- **The CLI speaks human.** `read`, `search`, `recent`, `context` and `write` print terminal-friendly output by default: `read` shows the engram address then the markdown verbatim, `search` lists one hit per line with a snippet and a paging footer. `--json` keeps every previous shape byte for byte.
- **Sync got twice as fast and stopped blocking the daemon.** A case-insensitive title index turns relation resolution into seeks, child rows insert in batched statements and chunking runs off the write transaction (1k-engram cold sync: 869 ms -> ~440 ms). The store lock no longer covers the walk-hash-parse pass at all, so searches keep answering while a large domain syncs, and a concurrent write landing mid-sync is deferred and reconciled instead of clobbered.
- **The watcher targets what changed.** A file event now syncs exactly the touched paths instead of rescanning the whole domain; anything ambiguous falls back to the full rescan automatically.
- **Search stopped paying double.** The embedding coverage snapshot is cached with strict invalidation and the query embedding runs outside the store lock, so a slow remote embedding endpoint no longer serializes every other request behind one search.
- **The embedding pipeline heals itself.** Batches write atomically, transient remote failures (429, 5xx, timeouts) retry with backoff honoring Retry-After and a background tick re-fires the worker whenever a backlog is left behind.
- **First-run polish.** `--help` opens with a quickstart, `domain add` works with just a name, `install`, `status` and `serve` point at the next step when nothing is registered, `delete` confirms at a real terminal (`--force` for scripts), model downloads show byte progress and timestamps read as "5m ago".
- Release binaries are built with thin LTO, turso opens with a busy timeout and a full reindex or wipe now truncates the WAL so rebuilt databases stay small.

## Fixes

- A hash or parse task that panicked mid-sync now lands in the sync report instead of silently dropping the file.
- Postgres: an embedding width change no longer intermittently fails chunk replacement with a cached-plan error, and a mid-batch embedding failure leaves nothing half-written.
- A failed source-file removal during a cross-domain move is logged instead of swallowed.

## Breaking changes

- The default (non `--json`) output of `read`, `search`, `recent`, `context` and `write` is now human text. Scripts parsing CLI output should pass `--json`, whose shapes are unchanged.
