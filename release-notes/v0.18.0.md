# Permission to come aboard

Knowledge can be reviewed before it lands now, and every unshared word belongs
to exactly one person until they say otherwise.

## New & Noteworthy

**Review mode.** A shared folder moves the moment somebody saves, so nobody
reviews anything: it is already there. `review: overlay` makes a domain's folder
reviewed truth, changed only by a merge that lands from GitHub, and every write
in it - yours or your agent's - joins its author's own private draft instead of
the file. Search, `read_engram`, `browse_domain`, `evolve_engrams` and the
routing prompt show your drafts stitched into what the domain already shares,
and nobody else's. `share_changes` proposes exactly your drafts. Turning review
off prints the plan first: fold each person's drafts into the folder, or discard
them.

**Draft share-links.** A draft nobody can see is a bad place to ask for a second
opinion. Mint a link on one of your drafts and hand it to one person: it opens
that page for the first account that presents it and nobody else. Reading is
what the link grants, typing needs a join, and revoking it, folding the draft or
discarding it ends it. It is the only door into a draft.

**The agent is a named peer in the document.** An agent rewriting the file
underneath you is how an afternoon disappears. While somebody has a page open in
the editor, an agent's edits compose into what they are looking at, its reads
answer that same text, and it stands in the participant strip by name for a
minute after each call, so nothing moves while you are not looking. A wholesale
overwrite asks the person first, and a client that cannot be asked is refused
rather than landing quietly.

**Agents sign in.** One shared HTTP endpoint is one agent with everybody's
access. `auth.mcp` puts a gate at the door: every account issues its own agent
token from Fluid's Agent access card or `crystalline users`, and the agent then
acts as its person, so a viewer's agent is read-only by construction. For hosted
clients that will never paste a token, `auth.oauth` makes Crystalline an OAuth
resource server - dynamic client registration, PKCE, one consent page - and your
profile lists every client you connected and revokes any of them.

**Sign in the way your company already does.** Generic OIDC login with PKCE,
discovery and JWKS rotation, or a proxy's forward-auth header quartet where an
SSO proxy already did the work. An account links an SSO identity explicitly, and
unlinking the last way into an account is refused.

**Private domains.** Not everything on a shared instance is everybody's. A
domain can be private, with an owner and an invited membership. To everyone else
it reads as absent rather than forbidden: no name, no count, nothing to guess
at, on every surface.

**Split an engram instead of retiring it whole.** When one fact in an engram
expires, retiring the bundle loses everything still true beside it.
`split_engram` moves the observations or sections you name into a new engram
with the source's tags, links the pair with `derived_from` and `split_into`, and
deletes nothing. V010 names the still-valid observations a retirement is about
to take down with it.

**Neighbours, at the moment you write.** A duplicate a sweep finds three weeks
later is a duplicate you already worked from. Write and edit receipts name the
nearest engrams to what just landed, Fluid shows the same panel after a save
(`capture.similar` turns it off), and V301 finds semantic twins: the same
knowledge in different words.

**A better trail behind every write.** The generated block records which model
wrote an engram beside who wrote it. MCP write results carry the share and
evolve nudges, throttled per person, so an agent working through the tools alone
hears what a person in Fluid would see. The session-end nudge now names what is
not durable, not only what is, and a source read into the knowledge leaves a
`type: ingestion` record with a `source_version`, so the next pass over it takes
the delta instead of starting over.

**Search first.** The routing block told an agent how to route a search and
never when to run one, so it searched too seldom. Two rules open it now: search
before you answer a question about this project's past, its people, its systems
or an unfamiliar name, and search before you start a task, on its subject.
`prompt system --domain` renders only the domains you name.

**Fluid reads wider.** One press of `\` drops the details column and the reading
measure with it. Diagrams take the full column or open over the whole window
with pan, zoom and keyboard, on mermaid 12. The lattice trio is the new mark
throughout.

**At ten thousand engrams.** Two embedding passes used to run at once, each
re-embedding what the other had in flight, for a fifth of the throughput and 280
MB of resident memory; there is one pass at a time now, and a request arriving
during one is folded into it and told so. `reindex --full` re-reads every file
and destroys nothing, so an interrupted rebuild no longer leaves a domain empty,
and a durable marker records that a rebuild is in flight and which kind it was.

**Smaller but handy.** `remove_domain` joins the tool list, and a domain nobody
has registered for a week has its leftover index rows collected. A title holding
a `/` or a `:` gets a note saying where the engram actually landed and what a
link to it has to say. `--version` names the copyright, the license and the
source, and `/health` says how the daemon was started and what it bound.

## Fixes

- A title with a colon in it (`Log: weekly garden notes`) looked exactly like a
  domain prefix, so a `[[link]]` to it never resolved. Crystalline's own writes
  link by permalink now, and a hand-written title link whose prefix names no
  registered domain is tried as a title in its own domain first (#65).
- The maintenance page fetched one global top-100 and filtered it in the
  browser, so a tally reading "Temporal 8" beside a single visible temporal row
  was the page telling on itself. The domain select and the family chips are
  query inputs now, and the page says when it is still fetching (#66).
- Domains were listed in registration order, which is meaningful to nobody.
  Sorted by name, server-side, so the sidebar, the CLI and the routing prompt
  agree (#67).
- The share dialog flattened the proposal it named into plain text. "Opened
  proposal #56." keeps its wording and the number is a link (#69).
- `doctor` was the one index-touching command with no daemon route, so a healthy
  daemon holding the index made the tool meant to diagnose the service die with
  a raw locking error. It also told you to sync a file that would never sync: a
  file whose frontmatter does not parse looked identical to an unsynced one.
- `sync` printed a "failed:" line for a file it could not index and still exited
  0, so nothing downstream, a CI step included, could tell that run from a clean
  one.
- An upstream rename that changed only the case of a path read as a deletion of
  one file and an addition of another, and the deletion was shareable.
- A knowledge base with a few hundred dangling links paid a full domain scan per
  link on every sync of every domain: over 500 dangling references, 2,355 ms
  down to 21 ms.
- An index file that would not open was deleted and replaced with an empty one,
  which took a virtual domain's only copy with it and reported success. It is
  renamed aside now, never removed, and the refusal that protects those engrams
  printed an export command that does not parse: both ways out run as printed.
- V105 told you to move an oversized engram's full text into a `type: source`
  engram, then flagged that engram as oversized. Source engrams get four times
  the budget.
- Creating a private domain under a name another account holds answered a server
  error. It answers 409, naming a remedy that works in the state it leaves.
- A GitHub device sign-in said nothing about the Authorize page that follows the
  code; a SAML-enforced organization's 403 was rewritten as "ask a maintainer to
  add you as a collaborator", which clears nothing. Both say what is going on
  and where to go.
- Copilot could end up with two identical managed hook entries, injecting the
  routing block twice per session.
- Fluid's full-width shortcut never fired on German, French, Spanish, Italian or
  Nordic keyboards, where the backslash itself is an Alt key.

## Breaking changes

None. Five behavior changes worth naming:

- The engram table gains an actor dimension, so the first start on 0.18.0
  resyncs the index once. File domains rebuild from disk, nothing on disk
  changes, and embeddings are kept.
- `reindex --full` no longer re-embeds: it re-reads and re-upserts every file
  and keeps every embedding whose chunk text is unchanged. Rebuilding 10,005
  engrams takes under a minute where re-embedding them takes an hour. The destructive path
  is `reindex --wipe`, for a database file that will not open, and it refuses on
  Postgres and while any virtual domain is registered.
- A read-only instance drops ten tools from the MCP list on a default install
  and thirteen once `github.enabled` is on, since the three collaboration verbs
  that write follow the same gate. The default list is 20 tools.
- `owner` is a reserved account name: it is the actor key the machine owner's
  own drafts are written under, so no login may be created under it.
- argon2 0.6 and rmcp 3.4.0. Hashes written by earlier versions still verify, so
  the argon2 bump is not a password reset, and the rmcp walk found the era
  routing, the handshake answer and the session rule byte-identical.
