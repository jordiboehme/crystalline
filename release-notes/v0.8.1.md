# Signed, sealed, delivered

## New & Noteworthy

- **macOS binaries are code signed and notarized.** Every release now signs the binary with an Apple Developer ID certificate under the hardened runtime and notarizes it with Apple before packaging, so a downloaded binary runs cleanly instead of hitting the "Apple could not verify" block. The signature travels into the standalone tarballs, the Homebrew tap and the Claude Desktop `.mcpb` bundles alike.
- **Keychain access grants now survive upgrades.** The binary carries the stable code signing identity `io.github.jordiboehme.crystalline`, so a keychain "Always Allow" for the stored GitHub token persists across versions instead of asking again after every update. Upgrading from an unsigned build prompts one final time, then never again.

Windows releases remain unsigned for now - verify against `SHA256SUMS` as before.

## Breaking changes

None.
