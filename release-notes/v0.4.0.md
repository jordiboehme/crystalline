## New & Noteworthy

- **`crystalline install`.** One idempotent command wires up a coding harness: MCP server registered, a session-start routing hook, a capture nudge and the skills copied into place. `crystalline uninstall` reverses exactly what install did and touches nothing else.
- **One skill to remember them all.** A consolidated memory skill covers recall, capture and sharing, and the MCP server now serves a live routing block as its own instructions - agents get onboarded at connection time, not by folklore.
- **Skills as release artifacts.** Zipped, versioned, downloadable.
- **Windows, properly.** An MSI in the release pipeline and an 8 MiB main-thread stack, so deeply nested futures stop flirting with the guard page.
- **Doctor knows your harness.** It reports what is installed where and warns when a hook would run an older crystalline lurking on the PATH.

## Fixes

- Explicit `--db`/`--config` overrides now always bypass the daemon instead of politely asking it about a different index.
