## New and Noteworthy

- **Create any domain over MCP.** `add_domain` now provisions any domain kind straight from an agent session: a local folder domain, a database-backed virtual domain (`virtual: true`) or a GitHub team domain (`repo: owner/name`). The mode follows the parameters, so onboarding a new knowledge domain no longer needs a CLI round trip.

## Fixes

- **Claude Desktop tool params.** The MCP list and map tool inputs (`configure` set/unset, `search`/`context`/`recent` domains, tag and type filters) now advertise a plain `array`/`object` JSON Schema instead of an `["array", "null"]` union that some clients stringified on the wire and then failed to deserialize. The same inputs also accept an explicit `null` as an empty value.
- **Claude Desktop chat mode connects.** The server answers the TypeScript MCP SDK's pre-`initialize` `server/discover` probe with `-32601` rather than letting the connection drop, which had left chat mode hanging while code mode worked.
- **verify action.** The verify GitHub Action downloads its binaries from the Crystalline release assets.

## Breaking changes

- None. The tool-param schema change accepts a missing key, an explicit `null` or a real value alike, so existing callers keep working.
