## Breaking changes

- **Intel macOS release files are now named `macos-intel`.** The platform token for Intel Macs changed from `macos-amd64` to `macos-intel`, so the standalone tarball and the Claude Desktop bundle are named `crystalline-v0.8.2-macos-intel.tar.gz` and `crystalline-v0.8.2-macos-intel.mcpb`. The Homebrew formula and the bundled verify action already point at the new names; only scripts that fetch the Intel Mac asset by its old name need the new token. Earlier releases keep their original file names.

**Full changelog**: https://github.com/jordiboehme/crystalline/compare/v0.8.1...v0.8.2
