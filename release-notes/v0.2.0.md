## New & Noteworthy

- **PostgreSQL, optional.** The storage layer went backend-agnostic: the embedded index stays the default, PostgreSQL with pgvector is now a choice for people with opinions about infrastructure. Cross-backend parity tests keep both honest.
- **Shared-database collaboration.** Several instances can share one index. Each file domain has exactly one hosting instance (arbitrated by lock and heartbeat, with stale takeover); everyone else reads. Knowledge captured anywhere is visible everywhere.
- **Virtual domains.** Engrams that live in the database itself: no folder, no files, fully portable, and `domain export` hands the markdown back whenever you want it on disk.

## Breaking changes

None.
