# Drafting Desk

The reviewing domain `fluid/e2e/smoke.spec.ts` settles draft conflicts in.
Its origin is never reached: the run writes the team's side into the base
snapshot under the state folder, the way a pull would.

## Scope

- Pages a person drafts while the team changes them

## When to Use

- Only by the browser smoke
